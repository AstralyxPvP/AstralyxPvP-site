## About AstralyxPvP

AstralyxPvP is an intense, India-based 1.9+ FFA (Free-For-All) Minecraft PvP server designed for players who crave fast-paced combat and skill-based battles. Step into the arena and prove your dominance with our unique ELO system, live leaderboards, and a vibrant community.

## Key Features

*   **1.9+ FFA PvP Combat**: Experience dynamic shield and axe combat that puts your skills to the test.
*   **ELO System**: Climb the ranks with our skill-based ELO system that tracks every kill and death.
*   **Live Leaderboards**: Monitor your performance in real-time with our constantly updated leaderboards.
*   **Cracked & Free**: Everyone is welcome! Join with any client and jump into FFA action for free.
*   **AstralyxAI Chat Assistant**: An integrated AI assistant powered by Google Gemini and secured with Cloudflare Turnstile, designed to help players with questions and provide information.
*   **Discord Integration**: An active Discord community for support, discussions, and updates.
*   **Mobile Optimization**: A dedicated mobile version of the website for a seamless experience across all devices.

## Technologies Used

This project leverages a combination of frontend web technologies and cloud services:

*   **Frontend**: HTML, CSS, JavaScript (Vanilla JS)
*   **Hosting**: Cloudflare Pages
*   **AI Integration**: Google Gemini (for AstralyxAI)
*   **Security**: Cloudflare Turnstile (for AstralyxAI)
*   **Version Control**: Git & GitHub

## Installation and Setup (Local)

To set up the project locally, follow these steps:

1.  **Clone the repository**:
    ```bash
    git clone https://github.com/AstralyxPvP/AstralyxPvP-site.git
    cd AstralyxPvP-site
    ```
2.  **Install Dependencies**:
    This project is primarily static and does not require complex backend dependencies. Ensure you use a web server (e.g., Live Server Extension for VS Code) to render the HTML files correctly.
