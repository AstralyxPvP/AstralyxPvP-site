# Astralyx PvP - React port

This repository contains a Vite + React port of the HallOfFame page from the original AstralyxPvP site.

- Build output is placed in /docs so you can serve it using GitHub Pages.

To run locally:

1. npm install
2. npm run dev

To build for GitHub Pages:

1. npm run build
2. Commit and push the generated /docs folder (Vite builds to docs automatically here)
