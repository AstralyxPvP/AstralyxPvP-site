## Über AstralyxPvP

AstralyxPvP ist ein intensiver, in Indien ansässiger 1.9+ FFA (Free-For-All) Minecraft PvP-Server, der für Spieler entwickelt wurde, die rasante Kämpfe und fähigkeitsbasierte Schlachten lieben. Treten Sie der Arena bei und beweisen Sie Ihre Dominanz mit unserem einzigartigen ELO-System, Live-Bestenlisten und einer lebendigen Community.

## Hauptmerkmale

*   **1.9+ FFA PvP-Kampf**: Erleben Sie dynamische Kämpfe mit Schild und Axt, die Ihre Fähigkeiten auf die Probe stellen.
*   **ELO-System**: Steigen Sie in den Rängen auf mit unserem fähigkeitsbasierten ELO-System, das jeden Kill und jeden Tod verfolgt.
*   **Live-Bestenlisten**: Verfolgen Sie Ihre Leistung in Echtzeit mit unseren ständig aktualisierten Bestenlisten.
*   **Cracked & Kostenlos**: Jeder ist willkommen! Treten Sie mit jedem Client bei und stürzen Sie sich kostenlos ins FFA-Geschehen.
*   **AstralyxAI Chat-Assistent**: Ein integrierter KI-Assistent, der von Google Gemini betrieben wird und über Cloudflare Turnstile gesichert ist, um Spielern bei Fragen zu helfen und Informationen bereitzustellen.
*   **Discord-Integration**: Eine aktive Discord-Community für Support, Diskussionen und Updates.
*   **Mobile-Optimierung**: Eine dedizierte mobile Version der Website für ein nahtloses Erlebnis auf allen Geräten.

## Technologien

Dieses Projekt nutzt eine Kombination aus Frontend-Webtechnologien und Cloud-Diensten:

*   **Frontend**: HTML, CSS, JavaScript (Vanilla JS)
*   **Hosting**: Cloudflare Pages
*   **AI-Integration**: Google Gemini (für AstralyxAI)
*   **Sicherheit**: Cloudflare Turnstile (für AstralyxAI)
*   **Versionierung**: Git & GitHub

## Installation und Einrichtung (Lokal)

Um das Projekt lokal einzurichten, folgen Sie diesen Schritten:

1.  **Repository klonen**:
    ```bash
    git clone https://github.com/AstralyxPvP/AstralyxPvP-site.git
    cd AstralyxPvP-site
    ```
2.  **Abhängigkeiten installieren**:
    Dieses Projekt ist hauptsächlich statisch und erfordert keine komplexen Backend-Abhängigkeiten. Stellen Sie sicher, dass Sie einen Webserver (z.B. Live Server Extension für VS Code) verwenden, um die HTML-Dateien korrekt zu rendern.
